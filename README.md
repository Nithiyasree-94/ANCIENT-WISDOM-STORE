# ANCIENT-WISDOM-STORE 🏛️
This is the first step in my journey.

Ancient Wisdom Store is a refined, aesthetically pleasing e-commerce web application dedicated to books and manuscripts. The platform features a classic, antique-inspired design using Google Fonts like Cinzel and Cormorant Garamond to evoke the feeling of an old-world library.

**✨ Features**
**Vibrant Collection:** Browse through curated categories such as Engineering, Self Improvement, Moral & Ethics, and Tamil Literature.

**Book Management:**

**Search & Filter:** Real-time searching and category-based filtering of the collection.

**Wishlist:** Save your favorite titles for later.

**Cart System:** Add multiple items to your cart with automatic total calculation.

**Unique Rental Service:** Includes a "Quick Rent" feature with hourly and daily pricing options.

**Token System:** Earn loyalty tokens on every purchase.

**Interactive E-Reader:** Previews of book content with a structured chapter navigation system.

**Seamless Payments:** Integrated simulation for various payment methods including UPI, Cards, and Net Banking.

**Responsive Design:** A fully functional mobile navigation menu ensures accessibility across devices.

**🛠️ Technology Stack?**
**Frontend:** HTML5, CSS3

**Scripting:** JavaScript (Vanilla JS)

**Typography:** Cinzel & Cormorant Garamond via Google Fonts

**Integration:** Razorpay Checkout SDK (UI representation)

**📂 File Structure**
**index.html:** The core structure of the single-page application, containing all sections from the home page to the checkout screen.

**style.css:** Comprehensive styling that defines the antique aesthetic, parchment-style backgrounds, and gold-themed accents.

**script.js:** The engine of the application handling state management for the cart, search logic, payment flows, and page navigation.
